# KOReader-page-calculator
Add the print reference to calculate the number of pages. Directly in KOReader

# Instructions:

Install it in the KOReader plugins folder. Open the reader, open a book, and once you’re inside the book, open the menu and go to the wrench icon (More Tools), where you’ll see Page Calculator. In the pop-up, enter the page number you want and press “calculate.” It will perform the adjustment in three steps. I don’t know why. This plugin doesn’t change KOReader’s page calculation; it simply sets the number of characters per page already present in KOReader.
